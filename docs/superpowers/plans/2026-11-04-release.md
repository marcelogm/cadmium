# Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Uma tag `v*` publica Flatpak, AppImage, zip e instalador do Windows, em x86_64 e arm64, num GitHub Release com a lista de downloads.

**Architecture:** Um workflow `release.yml` com um job por formato, cada um em matriz de runners nativos (x86_64 e arm64). Os jobs sobem artifacts; na tag, um job final confere a versão, junta tudo, gera `SHA256SUMS` e cria o Release. Os arquivos de integração com o desktop (ícone, `.desktop`, metainfo) ficam em `crates/cadmium-app/data/` e são usados por todos os formatos.

**Tech Stack:** GitHub Actions, flatpak-builder (GNOME 51), quick-sharun (Anylinux, container Arch), MSYS2 UCRT64/CLANGARM64, Inno Setup 6, embed-resource.

Spec: `docs/superpowers/specs/2026-11-04-release-design.md`
